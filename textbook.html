CHAPTER 3

ChatGPT 〜ひらめきと画像の友だち〜

🎨いちばんの得意技は「画像づくり」

ChatGPTのすごいところは、日本語でお願いするだけで画像を作ってくれることです。昔の画像AIは英語の呪文が必要でしたが、今は「こんな絵がほしいな」と話しかけるだけ。特にこんなことが得意です。

  • 文字入りの画像 … 「セール中！」と入ったお知らせ画像、インスタ投稿の表紙など。以前のAIは文字が崩れましたが、今はきれいに入ります
  • イラスト・キャラクター … 「やわらかい水彩風で」「絵本のタッチで」など、雰囲気の指定が通じます
  • 写真の変身 … 手持ちの写真を渡して「この写真をイラスト風にして」「背景だけ白にして」
  • 何度でも直せる … 出てきた画像に「もう少し明るく」「文字を大きく」と会話で修正できます
コツは「3点セット」でお願いすること。①何の画像か ②雰囲気 ③使いみち。この3つを伝えると、一発で好みに近づきます。
インスタ投稿用の画像を作ってください。 ①内容：【例：「今週の新着アイテム」という文字が入ったお知らせ画像】 ②雰囲気：【例：やさしいピンクとベージュ、女性向け、上品でかわいい】 ③使いみち：【例：メルカリショップのインスタ告知】 文字は大きく読みやすくしてください。

💡画像のほかに得意なこと

  • アイデア出しの壁打ち … 「子どもの自由研究のテーマを10個」「インスタのネタを20個」のような数出しが速い
  • ネーミング … ショップ名・企画名の案出し
  • 音声でおしゃべり … スマホアプリのマイクボタンで、家事をしながら声で相談できます
⚠️ 注意：無料プランの画像づくりは1日の枚数に上限があります（時期によって変わります）。大事な画像は、お願い文をしっかり練ってから作りはじめるのがおすすめです。

Gemini 〜Googleの秘書さん・スプシと在庫管理〜

🔍Geminiでやれること

  • 最新情報の調べもの … Google検索と直結しているので、「今日の」「最新の」情報に強い
  • 写真・スクショの読み取り … 手書きメモ、学校のお手紙、レシートを撮って渡すと文字にしてくれます
  • スプレッドシートの相談相手 … 表の整理のしかた・関数を日本語で聞けます
  • 長い動画・資料の要約 … YouTubeのURLを渡して「要点だけ教えて」

Googleアカウント（Gmailのアカウント）があれば、gemini.google.comですぐ使えます。

📦在庫管理表×Gemini 〜みんながつまずく5つのポイント〜

物販のみなさんの在庫管理表をたくさん見てきて、つまずくポイントは実はいつも同じです。表の作り方さえ直せば、AIが一気に働けるようになります。

  1. 1行1商品になっていない … 1つのセルに「バッグ3点」とまとめ書きすると、AIも関数も数えられません。1商品＝1行が鉄則です
  2. セルの結合を使っている … 見た目はきれいでも、AIにとっては表が壊れた状態になります。結合は使いません
  3. 言葉がバラバラ … 「売却済」「売れた」「済」が混ざると、別のものとして数えられます。書き方を1つに決めます
  4. 日付の形がバラバラ … 「8/4」「8月4日」「0804」の混在。「2026/08/04」の形にそろえます
  5. 仕入れ値と売値と経費が別のシートに散らばる … 1商品の情報は同じ行に横に並べます。行がそろえば利益は自動計算できます
この5つ、自分でチェックしなくて大丈夫。下のお願い文で、Geminiに表の健康診断をしてもらえます。
わたしの在庫管理表を整理したいです。今の表のスクリーンショットを渡します。 ①この表の問題点を、やさしい言葉で教えてください ②「1行1商品・結合なし・言葉と日付の統一」ができた理想の表の見本を作ってください ③今の表から見本の形へ、何をどの順番で直せばいいか、手順を1つずつ教えてください 【ここにスプレッドシートのスクショを貼る】

📊整った表は「分析」までできる

表が整うと、Geminiはただの入力係から経営参謀に変わります。月に1回、表のスクショ（または範囲をコピーした文字）を渡してこう聞いてみてください。

わたしの在庫管理表のデータです。次の4つを教えてください。 ①今月いちばん利益が出た商品と、その理由の推測 ②仕入れてから売れるまでが遅い「眠り在庫」はどれか ③値下げしてでも早く売ったほうがいい商品はどれか ④来月の仕入れで意識するといいこと むずかしい言葉を使わず、明日からできることだけ教えてください。 【ここに表のスクショかコピーを貼る】

※ スプレッドシートの画面の中にGeminiのボタンが出る機能もありますが、有料版限定のことがあります。無料で使うなら「スクショやコピーを渡して相談する」この方法がいちばん確実です。

🤖GAS（Google Apps Script）って何？

Googleの道具の中で、いちばん「？」となるのがGASです。でも正体はとても単純です。

図1：GASの正体
📋 あなたのスプレッドシートふだん使っている表 ＋ 🤖 GAS表についてくる小さなロボット
どのスプレッドシートにも、実は最初から「ロボット置き場」がついています。
メニューの「拡張機能」→「Apps Script」がその入り口です。

GASは、スプレッドシートに住んでいるロボットです。ふだんは寝ていますが、「命令書」（これがプログラム）を書いて渡すと、あなたの代わりに表を読んだり、書いたり、メールを送ったりしてくれます。しかも完全無料です。

図2：ロボットが働く流れ（「トリガー」＝目覚まし時計）
⏰ 毎朝7時になる目覚まし時計（トリガー） ↓ 🤖 ロボットが起きて命令書を読む ↓ 📋 表をチェック「今日発送の商品は…」 ↓ 📩 あなたにメールでお知らせ
「トリガー」＝ロボットを起こす目覚まし時計。「毎朝7時」のほかに
「表に新しい行が増えたら起きる」という設定もできます。
図3：実際に動いている使用例（感想の自動お返事係）
👩 生徒さんが感想フォームを送信 ↓ 📋 スプレッドシートに1行増える ↓ 🤖 GASが気づいて起きる ↓ 💌 お礼のメッセージを自動でお返事
これはMeroneで実際に動いている仕組みです。人間は1回設定するだけで、
あとは24時間365日、ロボットが働き続けてくれます。
いちばん大事なこと：命令書（プログラム）は自分で書かなくていい。AIに「こういうことがしたい」と日本語で伝えると、命令書はAIが書いてくれます。あなたの仕事は「やってほしいことを決める」ことと「貼り付ける」ことだけです。
スプレッドシートのGAS（Apps Script）を作ってください。わたしはプログラムがまったくわかりません。 やりたいこと：【例：この在庫表で、仕入れから30日たっても売れていない商品を、毎週月曜の朝にメールで知らせてほしい】 表の内容：【ここに表のスクショを貼る】 ①コードを全部作ってください ②どこに貼り付けて、どのボタンを押せばいいか、手順を1つずつ教えてください ③トリガー（自動で動く設定）のやり方も教えてください
CHAPTER 5

Claude 〜このらぼの主役・3つの入り口〜

💜Claudeの性格

Claudeは「長い話をじっくり聞いて、深く考える」のが得意なAIです。文章が自然でやさしく、相談ごとの受け答えが丁寧。そして会話しながらアプリまで作れてしまうのが最大の特徴です。みなさんのカルテで動いている「AIくみこ」も、この教科書も、らぼの申込サイトも、ぜんぶClaudeで作られています。

🚪3つの入り口の使い分け

Claudeには入り口が3つあって、ここでみんな迷います。でも役割はハッキリ分かれています。

図4：Claudeの3つの入り口
💬 チャットふだん使いの相談窓口 📁 Projects資料を覚えた専用の部屋 ⌨️ Claude Codeパソコンを動かす上級版
らぼで使うのは左の2つ。Claude Codeは「いつか」でOKです。
💬 チャット📁 Projects⌨️ Claude Code
ひとことでその場の相談窓口覚えてくれる専用ルームパソコン操作の職人
使いどき献立・文章・調べもの・アプリづくり。まずは全部ここでOK同じテーマを何度も相談するとき。資料を最初に渡しておくと毎回説明しなくてすむ本格的な開発・パソコンのファイル整理の自動化など
例「今夜の献立を考えて」「在庫の部屋」を作り在庫表を覚えさせる→毎回「今週の分析して」だけで通じるプロ・上級者向け（有料プラン）
らぼでは◎ メインで使います◎ 慣れてきたら△ 卒業後のお楽しみ
Projectsのイメージは「かかりつけのお医者さん」。ふつうのチャットは初診なので毎回イチから説明が必要ですが、Projectsという部屋に家族構成・在庫表・お仕事の内容を最初に置いておけば、2回目からは「いつもの、お願い」が通じます。「何度も同じ説明をしているな」と気づいたら、Projectsを作るタイミングです。

✨アーティファクト 〜あなたの作品置き場〜

Claudeに「アプリを作って」とお願いすると、画面の横に実際にさわれる作品が現れます。これが「アーティファクト」です。

図5：アプリができて、みんなに配るまで
💬 「子どもの歯みがき表アプリを作って」 ↓ ✨ 画面の横にアプリが出現（アーティファクト） ↓ 🔗 「共有」を押すとURLができる ↓ 👨‍👩‍👧 家族のスマホに送れば、みんな使える
らぼの最終ミッション「自分のアプリ2つ」も、この方法で完成させます。
くわしいお願いのしかたは「魔法の言葉」のページにあります。
CHAPTER 6

GitHub 〜作品の倉庫と展示場〜

🏠GitHubの正体

GitHubは、ひとことで言うと「作品の倉庫」と「展示場」がセットになった場所です。世界中の人がプログラムの保管に使っていますが、むずかしく考える必要はありません。

図6：GitHubのしくみ
💻 あなたの作品Claudeと作ったアプリなど ↓ アップロード（保管） 📦 GitHub＝倉庫作品を安全に保管。昔の版も全部残る ↓ 公開スイッチON 🏛 GitHub Pages＝展示場あなた専用のURLで世界に公開
このらぼの申込サイトもカルテも、この教科書も、
ぜんぶGitHub Pagesの「展示場」に置いてあります。しかも無料です。

倉庫のいいところは2つあります。①消えない（パソコンが壊れても作品は無事）②歴史が残る（直す前の版にいつでも戻れる。「上書きして前のが消えた！」がなくなります）。

🤔で、わたしに必要？

結論：らぼの間は、なくても大丈夫です。アプリの公開はClaudeの「共有」ボタン（図5）でできるので、GitHubなしで最終ミッションまで完走できます。

GitHubが必要になるのは、次の段階に進みたくなったときです。

  • 作品に自分だけの覚えやすいURLをつけたい
  • お客さま向けのちゃんとしたサイトとして育てたい
  • 作品がたくさん増えて、1か所で安全に管理したい
⚠️ 先に知っておいてほしい注意が2つ。①画面がぜんぶ英語です（翻訳しながらで大丈夫）。②無料プランで展示場（Pages）を使うと、作品の中身（コード）はだれでも見られる状態になります。パスワードや個人情報をコードの中に書かないこと。ここだけ守れば安全です。

興味がわいた方は、勉強会で画面をお見せします。焦らなくて大丈夫です。

CHAPTER 7

無料での賢い使い方 〜お金をかけない作戦〜

🎫無料でどこまでできる？

無料でできること知っておくこと
ChatGPT会話はたっぷり。画像づくりもOK画像は1日の枚数上限あり。混んでいる時間は性能が下がることも
Gemini会話・調べもの・写真読み取り。Googleアカウントだけで使える無料枠が比較的ゆったり。雑用係に最適
Claude会話・アプリづくり・Projectsも無料で使える回数が少なめで、上限に届くと数時間お休みに。使いどころを選ぶのがコツ
GASぜんぶ無料上限を気にする必要はほぼなし
GitHub倉庫も展示場も無料無料プランは作品の中身が公開になる（CHAPTER 6の注意）

※ 各社の無料枠は時期によって変わります。「今日は上限です」と言われたら、翌日や数時間後に回復します。

🧠賢い人の使い分け作戦

  1. 雑用は分散する … 調べもの・写真の読み取りはGeminiへ。アイデア出しと画像はChatGPTへ。無料枠は「3人分」あると考えます
  2. Claudeの無料枠は「ここぞ」に温存 … Claudeがいちばん力を発揮するのは、じっくり相談とアプリづくり。短い雑用で使い切らないこと
  3. お願い文を練ってから送る … 何度もやり直すと回数がもったいない。この教科書のコピペ文のように、①やりたいこと②材料③条件をまとめて1回で渡すのが節約のコツです
  4. 迷いごとの相談はカルテへ … あなたのカルテのAIくみこは回数を気にせず使えます。「どのAIに聞けばいい？」もAIくみこに聞いてOK
  5. 課金するなら、最初の1つはClaude … らぼの本命だからです。毎日アプリづくりをしたくなったら検討する、で十分。それまでは無料で困りません
CHAPTER 8

悩み別・解決レシピ集 〜コピペで今日から〜

ここからが、この教科書の本番です。カルテに届いた悩みに、「どのAIで・どうやって」をぜんぶレシピにしました。自分の悩みに近いところを開いて、お願い文をコピーして、【 】を自分の内容に書きかえて送るだけ。まずは1つ、今夜ためしてみてください。

⏰ 時間がない・タスクに追われる悩みの40%
「仕事と育児の両立でタスクに追われて、効率化を考える余裕もない」「何の作業があるのかわからなくなって、その場しのぎになってしまう」

使うAI：Claude（またはChatGPT）
コツは、整理してから相談しないこと。散らかったまま、ぜんぶ吐き出すのが正解です。仕分けはAIの仕事です。スマホのマイクボタンで喋るだけでOK。

今から、頭の中にあるやること・気になっていることを、思いつくまま順番バラバラに書きます。整理しないで書くので、あなたが整理してください。 ①今日やるべき順に並べ替えてください ②15分以内でできるものに★をつけてください ③わたしがやらなくてもいいもの（AI・家族・道具に任せられるもの）に♻をつけて、任せ方も教えてください 【ここに思いつくまま全部書く（喋るのでもOK）】

✨ ワンポイント：これを毎晩やると、朝「今日なにからやるんだっけ」と考える時間が消えます。♻マークの数が、あなたに戻ってくる時間です。

💼 仕事を効率化したい悩みの40%
「日報のスクショを毎回手で表に転記している」「昔ながらのやり方のまま事務作業がまわっていて、効率が悪い気がする」

使うAI：Gemini（読み取り係）＋Claude（マニュアル係)
効率化の第一歩は「転記をやめる」こと。第二歩は「マニュアルを作って人に渡せるようにする」ことです。

この画像の内容を、表の形にして書き出してください。 列は 【例：日付・名前・報告内容・金額】 の順でお願いします。 【ここにスクショや書類の写真を貼る】
わたしの仕事の手順を今から話すので、ほかの人に渡せるマニュアルにまとめてください。 ・手順に抜けや曖昧なところがあれば、質問してください ・「初めての人がこれだけ見ればできる」レベルを目指してください 【ここに仕事の手順を思いつくまま話す】

✨ ワンポイント：毎日やっている作業こそ、GAS（CHAPTER 4の図3）で自動化できないかAIに相談する価値があります。「この作業、自動にできる？」と聞くだけで道が開けます。

👧 子育て・宿題・寝かしつけ悩みの37%
「子どもが夏休みの宿題を計画的にできない」「寝かしつけに時間がかかって自分の時間がない」「きょうだい喧嘩にどう声をかければいいか」

使うAI：Claude
コツは、お子さんの年齢・性格・状況をしっかり伝えること。「うちの子専用」の答えに変わります。宿題は親が管理をやめて、AIの計画に乗せると親子ともに楽になります。

子どものことを相談させてください。 子ども：【例：小4男子。ゲームが好き。コツコツは苦手】 困っていること：【例：夏休みの宿題が残り◯◯。声をかけるとケンカになる】 ①8月末までに終わる計画を、1日30分以内の量で立ててください ②ゲームのように進み具合が見えるしかけを入れてください ③親のわたしが言うとよい声かけを10個ください（命令にならない言い方で）

✨ ワンポイント：この相談をClaudeのProjects（「子育ての部屋」）でやると、子どもの性格を覚えたまま何度でも続きが相談できます。寝かしつけ・食事・声かけ、ぜんぶ同じ部屋でどうぞ。

🛍 物販・メルカリをもっとうまく悩みの37%
「洋服の写真が黄色っぽくなってしまう」「説明文を書くのに時間がかかる」「在庫がどこにあるかわからなくなる」

使うAI：Claude または ChatGPT（説明文）＋Gemini（在庫表・CHAPTER 4参照）

✨ ワンポイント：写真が黄色くなる悩みは、アプリより「昼間に窓際で撮る」が最強の解決策です。値段づけは、必ず自分でメルカリの「売り切れ」検索をして実際に売れた価格を見ること。AIの推測より市場の事実が主役です。

✨ ワンポイント：冷蔵庫の中身の写真を撮って「これで作れる夕食を3案」と送る技も便利です。買い物前のスキマ時間にどうぞ。

⚠️ 大切なこと：痛みが続く、眠れない日が続く、気分の落ち込みが重い。そんなときは、AIより先にお医者さまや専門機関に相談してください。AIは記録係と、通院時に症状を正確に伝えるお手伝い役です。

2026年秋・AIの新顔図鑑 〜Astra・Muse・新しいClaudeとGemini〜

📡この秋、何が変わった？（2026年11月10日時点）

この数か月で、AIの世界はにぎやかでした。ChatGPTの最上位「GPT-6 Astra」、Metaの新顔「Muse（ミューズ）」が日本上陸、Claudeは文書・スライド・デザインが無料で作れるようになり、Geminiは手描きの絵からアプリを作れるように。ニュースを追いかける必要はありません。この章で「自分の毎日に関係あるところ」だけ、ざっくりつかんでおきましょう☺️

先に結論：らぼの主役はClaudeのまま。新顔は「用事があるときだけ呼ぶ」で十分です。「新しいAIが出た＝乗りかえ」ではなく、「自分の困りごとが1つ楽になるか」だけで判断します。

🧭新顔4つを、ひと目で

何者？らぼ生にうれしい点お金・条件
GPT-6 Astra
（ChatGPT）		ChatGPTの最上位モデル。パソコンの画面を見てマウスとキーボードを動かし、資料づくりまで通しでこなす「調べて → 資料にまとめる」が一度で終わる。旅行のしおり、A4のお知らせ作りなど無料プランでは使えません。有料でも回数に上限。PC操作はパソコン版のみ（スマホ不可）
Muse
（Meta）		「答えるAI」ではなく「代わりに動く、あなた専属の秘書」。Googleカレンダー・Gmail・Instagramとつないで、リマインド・買い物リスト・メール整理までこなす。10/23から日本でも「毎朝7時に今日の予定と持ち物を教えて」「このレシピから買い物リストを作って」が頼める。送信・購入の前は必ず「やっていい？」と聞いてくる基本は無料（週の上限あり）。有料は月3,499円〜。18歳以上・Metaアカウントが必要
Claude
（Anthropic）		新モデルが続々（Opus 5.5 → Sonnet 5.5 → Haiku 5.5 → Fable 5.2）。そしてDocs・Slides・Design が無料プランでも正式に使えるように勉強会の資料、お知らせ文書、スライドが「会話の中で」作れる。アプリづくりは今まで通り主役Docs・Slides・Designは無料。「向こうから連絡してくる」Claude Duetは米国で順番待ち中（日本は未定）
Gemini
（Google）		チャットの中でドキュメント・スライド・スプレッドシートを作って直せる。紙に描いたアプリの絵を写真で渡すと、アプリにしてくれる（Canvas）在庫表やスプシの相談がさらに楽に。「毎朝8時に今日のやることを送って」のような予定アクションも基本は無料。動画づくり（最長15秒）は有料プラン向け。「Gems」は11/17から「Skills」に置きかわります

※ 各社の提供状況・料金は変わります（2026年11月10日時点の公開情報）。「使えない」と出たら、プランか地域の順番待ちです。あわてなくて大丈夫。

🤖GPT-6 Astra 〜「賢い回答」から「作業の代行」へ〜

9月3日に発表された、ChatGPTのいちばん上のモデルです。これまでのAIは「答えを返す」のが仕事でしたが、Astraはパソコンの画面を見ながら、マウスとキーボードを自分で動かして作業を進めるのが特徴です（Computer Use）。調べものから資料づくりまで、ひとつづきで頼めます。

  • できること … 「来月の旅行、移動と休憩を入れた案を比べて、大きな文字のしおりにして」「町内会のメモから、日時と場所が目立つA4のお知らせを作って」
  • 知っておくこと … 無料・Goプランでは使えません。Plusでも回数の上限にすぐ届きます。PC操作はパソコン版だけで、スマホからは使えません
  • らぼ生の答え … いまは「知っているだけ」で十分。アプリづくりと相談はClaude、画像はChatGPTの無料で困りません。「月額を払ってでも、調べる→資料にする、を毎週やる」人だけ検討を
⚠️ 代わりに動くAI全般に言えること：「送信・購入・予約は自分で確認する」と最初に伝えておきましょう。ログインしているサイトを操作されることがあるので、触ってほしくないサイトはログアウトしておくと安心です。

おまけ：11月4日からChatGPTの画像づくりが新しくなり（Images 2.6）、作るのが速く、動く画像（GIF）も作れます。インスタのストーリーに使えそうですね。

🪄Muse（ミューズ）〜あなた専属の「秘書」。リマインドから買い物まで〜

Instagramを運営するMetaが作ったAIで、10月23日から日本でも使えるようになりました（北米の次に日本）。iPhone・Android・ブラウザ（muse.ai）から、Metaアカウントで始められて、基本は無料です。

これまでのAIは「聞けば答える」でした。Museは「頼んでおくと、時間が来たら向こうから動く」のが違いです。アプリを閉じていても働き、投稿・メール送信・購入のような大事な場面では必ず「やっていい？」と確認してきます。OKを押すまで、勝手には動きません。つまり、家に秘書さんが1人来たと思ってください。

🏠主婦の毎日で、秘書に頼めること

  • 朝のリマインド … Googleカレンダーとつないで「毎朝7時に、今日の家族の予定と持ち物、ゴミの日を知らせて」。Museのアプリにメッセージで届きます（通知をオンに）
  • 「覚えておいて」 … 家族の人数、子どもの学校行事、アレルギー、夫の苦手な食べもの。一度伝えると、次からそれを前提に提案してくれます（やめたいときは「忘れて」でOK）
  • 献立 → 買い物リスト … Instagramで保存したレシピ動画から買い物リストを作る、「今週の献立と買い物リストを作って、日曜の夜に送って」
  • 学校・園からのメール整理 … Gmailとつないで「今週、返事や提出が必要なメールだけ一覧にして」。返信は下書きまで。送るのは自分
  • 家計まわり … 使っていないサブスクの見直し、欲しいものの値下がり追跡。購入の前は必ず確認が入ります
  • 旅行・予約の下調べ … 宿や観光の候補を比べて表にする。予約も頼めますが、最初は「探すだけ」で
  • 副業でInstagramをしている人 … プロアカウントをつなぐと、インサイト（数字）を読んで改善点や来月の投稿カレンダーまで作ってくれます（くわしくは下の早見表）
最初にやる3つ：①設定「データコントロール」の「AIモデルの改善に協力」をオフにする（最初はオンになっています）②つなぐのは必要なものだけ（まずGoogleカレンダーから。お店用のInstagramはOK、個人のInstagramはつながない）③慣れるまで「承認」は毎回自分で押す。

STEP 1｜秘書に自己紹介する（最初の1回だけ）

これから、私の秘書として手伝ってください。次のことを覚えておいて。 ・家族：【例：夫・小2の娘・年中の息子】 ・毎週の予定：【例：火曜はピアノ、木曜は夫が遅い、燃えるゴミは月・木】 ・食事のこと：【例：息子は卵アレルギー、夫は魚が苦手】 ・私の仕事：【例：メルカリで不要品を出品中、午前中が作業時間】 送信・購入・予約は、必ず私に確認してから。

STEP 2｜毎朝のリマインドを頼む

毎朝7時に、今日の予定を知らせてください。 Googleカレンダーの家族の予定と、持ちもの・ゴミの日を見て、 「今日の予定」「持っていくもの」「今日やる3つ」の順に、短くまとめてください。
⚠️ 秘書さんも間違えます。日時はカレンダーで最終確認、送ったメールは取り消せないので返信は自分で送る、「リセット」は履歴も予定も全部消えるので押さない。この3つを守れば安心です。Museが作る画像は文字が崩れやすいので、文字はあとから自分で入れるのがおすすめ。

💜Claude 〜モデル名は気にしない。「Docs・Slides・Design」が無料に〜

この秋、Claudeは新しいモデルが立て続けに出ました（Opus 5.5・Sonnet 5.5・Haiku 5.5、そして11月9日に Fable 5.2）。名前がたくさんあって迷いますが、らぼ生がやることは何も変わりません。頼み方（CHAPTER 9の5点セット）が良ければ、どのモデルでもちゃんと動きます。選ぶ画面で迷ったら、いちばん上のものを選べば大丈夫。

それより大きいのは、10月8日の発表。Docs（文書）・Slides（スライド）・Design（デザイン）が、無料プランでも正式に使えるようになりました。「会話の中で、資料ができる」ので、らぼ生にはいちばん実用的なニュースです。

  • Docs … お知らせ文、手順書、自己紹介シート。「このメモを、A4一枚のお知らせにして」
  • Slides … 勉強会の発表、家族会議の資料。「作ったアプリの紹介を、5枚のスライドにして」
  • Design … インスタ投稿の下書き、チラシの案。「やさしいピンクで、文字は大きく」
  • Claude Duet（10/21発表）… 朝に要約を送ってきたり、離席中に下調べを進めたりする「向こうから連絡してくるClaude」。いまは米国の有料プランで順番待ち。日本はまだです
あなたは発表資料づくりのプロです。 私が作ったアプリ【例：旅行の持ち物リスト】を、らぼの勉強会で紹介します。 Slidesで5枚のスライドにしてください。構成は「①困りごと ②作ったもの ③頼み方の工夫 ④使ってみた変化 ⑤次にやること」。文字は大きく、1枚に伝えることは1つ。 まず1案ください。あとで一緒に直します。

🟦Gemini 〜スプシの秘書が、資料も作れるように〜

  • 資料がチャットの中で作れる（10/29〜）… ドキュメント・スライド・スプレッドシートを作って、その場で直せます。在庫表の相談のあと「これを表にして」がそのまま通ります
  • 手描きの絵がアプリになる（11/6〜）… 紙に描いたアプリの画面を写真で渡し、ツールで「Canvas」を選んで「このアプリのコードを生成して」。色や文字もその場で調整できます。※らぼでのアプリづくりの本命はClaudeのまま。Geminiは「絵から試す」入口として
  • 予定したアクション … 「毎朝8時に、今日のやることを3つにしぼって送って」のような、決まった時間の仕事を頼めます
  • Gems → Skills … 自分用に作った「Gems」は11月17日から「Skills」に置きかわります（自動で移ります。あわてなくて大丈夫）
  • 動画づくり（Gemini Omni 1.2 Flash、11/5〜）… 最長15秒の音声つき動画。有料プラン向けなので、まずは知っているだけでOK

🗓最新AI 3日間コース 〜読むだけで終わらせない〜

1日15分×3日で、新顔を「自分の道具」にします。目標は「朝、秘書からのメッセージで1日が始まる」状態。終わったら第2回テストで確かめて、カルテに提出してください。

DAY 1｜Claudeで「資料」を1枚作る（無料）
上の「Slides」のお願い文をコピーして、自分の作ったアプリ（まだなら「作りたいもの」）を5枚のスライドに。できたら1枚目のスクショを保存。
DAY 2｜SNSの投稿を1本、AIで作る
ChatGPTで「文字入りの投稿画像」（CHAPTER 3の3点セット）＋投稿文（5点セット）。インスタをしていない人は、家族やお友だちへのお知らせ画像でOK。
DAY 3｜Museを「秘書」にする
Museを入れて、上のSTEP 1（自己紹介）とSTEP 2（毎朝のリマインド）のお願い文を送る。翌朝、本当に届くか確かめる。Museを入れたくない人は、Geminiで「毎朝8時に、今日のやることを3つにしぼって送って」の予定アクションを1つ作る（下のお願い文）。
提出｜カルテに1〜3行
カルテの困りごと欄に【最新AIコース 提出】と書いて、「何を試して・何が楽になったか・つまずいた所」を1〜3行。くみこが読んでお返事します。
毎朝8時に、私の今日のやることを送ってください。 やることのメモ：【例：出品3点・保育園の提出物・夕飯の買い物・妹に電話】 全部ではなく「今日やる3つ」にしぼって、順番と理由を一言ずつ添えてください。
合言葉は「主役はClaude、新顔は用事があるときだけ」。全部を使いこなそうとすると疲れます。3日間で、自分に関係ある1つが見つかれば大成功です☺️
